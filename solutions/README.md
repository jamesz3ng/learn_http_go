# Reference solutions: spoilers!

These are complete, commented implementations of every package in the course,
at their **final** state (stage 26). They pass every stage's tests.

Use them **after** you've passed a stage, to compare approaches, or as a
last resort when you're stuck after using every hint. Reading a solution
teaches much less than writing one; if you do read one, close it and write
your own version from memory.

Because they show the final state, a file may contain code for stages you
haven't reached yet. Comments like `// Stage 15` mark where each piece
belongs.

| Package | Stages |
|---|---|
| [rawhttp](rawhttp/) | 1 |
| [gobin](gobin/) | 2, 4, 6, 8, 9, 11, 13, 15, 17, 19, 21, 23, 24 |
| [gocurl](gocurl/) | 3, 5, 7, 12, 14, 18, 22, 24 |
| [kvclient](kvclient/) | 10, 16, 20 |
| [loadgen](loadgen/) | 25 |
| [proxy](proxy/) | 26 |

There's rarely one right answer. If your code passes the tests and you can
explain why it's correct, it's a good solution.
